### 3. AllergenX — Allergy Awareness iOS App
An iOS app designed to help the 32 million Americans living with allergies manage their condition more safely and confidently. AllergenX tackles four common allergy challenges in one place:

- **Food label scanning** — detects hidden allergens in ingredient lists using the Nutritionix AI API
- **Pollen tracking** — provides real-time local pollen levels using the AccuWeather API
- **EpiPen reminders** — alerts users before their emergency medication expires
- **Emergency notifications** — quickly notifies emergency contacts during an allergic reaction

**Built with:** Swift, Xcode, AccuWeather API, Nutritionix AI API
